# fix-hvp
Python code generated by Gemini (and lightly debugged by Claude) to fix data loss due to this Moodle mod_hvp plugin issue, https://github.com/h5p/moodle-mod_hvp/issues/632

You would need to replace the `vv_` in the code with your table prefix.

I had run this on a local machine which had the backup database instance locally installed and available at port 3306, with a tunnel to the live database at port 3316.

My tunnel was created like this,
```
ssh theuser@serverhostname  -L 3316:localhost:3306
```
